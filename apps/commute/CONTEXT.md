# 출근부 용어집

출근부(`apps/commute`) 코드·이슈·문서에서 쓰는 말을 정리한다. 같은 것을 가리킬 때는 여기 적힌 말만 쓴다.

## 사용자

| 용어       | 코드 이름                        | 뜻                                                                                                    |
| ---------- | -------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 근로장학생 | `worker` (API), `STUDENT` (역할) | 출근부로 근무를 신청하고 기록하는 학생. 화면 문구에서는 "근로학생"으로 줄여 쓴다                      |
| 관리자     | `ADMIN` (역할)                   | 근로장학생의 근무·신청·업무를 관리하는 직원                                                           |
| 역할       | `role`                           | 로그인한 사용자가 근로장학생인지 관리자인지. 서버가 로그인 응답으로 알려 주고, 화면에서 고르지 않는다 |
| 학교 메일  | `email`                          | `@konkuk.ac.kr`로 끝나는 메일. 로그인 아이디로 쓴다                                                   |

## 인증

| 용어        | 코드 이름             | 뜻                                                                                                                              |
| ----------- | --------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 로그인      | `login`               | 학교 메일과 비밀번호로 들어가는 것. 성공하면 역할에 따라 근로장학생은 학생 홈(`/`), 관리자는 관리자 홈(`/dashboard`)으로 간다   |
| 승인 대기   | `PENDING_APPROVAL`    | 회원가입은 했지만 관리자가 아직 승인하지 않은 계정. 로그인할 수 없고, 로그인하면 승인 대기 화면(`/pending-approval`)으로 보낸다 |
| 로그인 실패 | `INVALID_CREDENTIALS` | 메일이 없거나 비밀번호가 틀린 경우. 둘을 구분하지 않고 같은 문구로 안내한다                                                     |
| 페이지 보호 | —                     | 로그인하지 않은 사용자나 역할이 맞지 않는 사용자를 다른 화면으로 보내는 것. 로그인 상태를 어디에 저장할지와 함께 따로 다룬다    |
| 로그인 유지 | —                     | 브라우저를 닫아도 로그인 상태가 남는 것. 페이지 보호와 함께 따로 다룬다                                                         |

## 근로신청

| 용어            | 코드 이름         | 뜻                                                                                                                                                                                                                                                                                          |
| --------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 근로신청        | `workApplication` | 관리자가 다음 달 근무 신청을 여는 것과 그 기준. 관리자 화면에서는 다음 달 하나만 열고 고친다. 연 뒤에 기준을 고치면 그때까지 들어온 제출은 모두 초기화된다                                                                                                                                  |
| 신청 대상       | —                 | 그 달 근무를 신청할 수 있는 근로장학생. 관리자가 따로 고르지 않고, 승인된 모든 근로장학생이 신청할 수 있다                                                                                                                                                                                  |
| 그 달 근로학생  | `workers/monthly` | 그 달 근무를 실제로 신청한 근로장학생. 관리자가 미리 고른 명단이 아니다                                                                                                                                                                                                                     |
| 근로신청 요약   | —                 | 근로신청 관리 화면 오른쪽 패널. 신청을 열기 전에는 빈 상태를, 연 뒤에는 모든 근로장학생의 제출 현황을 카드로 보여 준다                                                                                                                                                                      |
| 제출            | —                 | 근로장학생이 그 달 근무 시간을 신청한 것. 신청 기간 안에는 여러 번 고칠 수 있고, 마지막으로 낸 신청이 그 학생의 제출이다                                                                                                                                                                    |
| 미제출          | —                 | 신청 기간이 시작됐지만 아직 한 번도 제출하지 않은 상태. 미충족에 함께 센다                                                                                                                                                                                                                  |
| 총 제출시간     | —                 | 마지막 제출에 담긴 그 달 근무 시간의 합. 미제출이면 0시간                                                                                                                                                                                                                                   |
| 최근 신청       | —                 | 마지막으로 제출한 시각                                                                                                                                                                                                                                                                      |
| 충족 / 미충족   | —                 | 총 제출시간이 월간 최소 이상, 월간 최대 이하이면 충족이고 아니면 미충족. 주간 기준으로는 판정하지 않는다. 충족 + 미충족 = 전체 근로장학생                                                                                                                                                   |
| 상태순          | —                 | 근로신청 요약의 기본 정렬. 미충족(미제출 포함)이 먼저, 같은 상태끼리는 이름순. 그 밖에 이름순·최근 신청순이 있다                                                                                                                                                                            |
| 근로신청 시간표 | —                 | 근로신청 요약의 "시간표 자세히보기"로 가는 화면 (근로신청 관리 아래). 그 달 제출을 주 단위 시간표로 모아 보여 준다. 관리자가 편집하기로 칸을 넣고 빼면 그 학생의 제출(총 제출시간·충족 판정)에 바로 반영되고, 최근 신청 시각은 바뀌지 않는다. 동시 근무 최대 인원과 관계없이 편집할 수 있다 |
| 정원 도달       | —                 | 근로신청 시간표에서 칸 인원이 동시 근무 최대 인원 이상인 칸. 시안에는 빨간 테두리로 그려져 있지만, 지금은 색을 따로 칠하지 않는다                                                                                                                                                           |

## 근로시간 관리

| 용어                  | 코드 이름           | 뜻                                                                                                    |
| --------------------- | ------------------- | ----------------------------------------------------------------------------------------------------- |
| 근로시간 관리         | `ADMIN_WORKTIME`    | 사이드바 메뉴. 들어가면 수정요청 화면이 나온다. 예전 주간 시간표 편집 화면은 근로신청 시간표로 옮겼다 |
| 수정요청              | `workChangeRequest` | 근로장학생이 확정된 근무 칸을 추가·삭제해 달라고 보내는 요청. 승인 대기·승인·반려 상태가 있다         |
| 신청 완료             | —                   | 수정요청 시간표에서, 고른 요청의 학생이 이미 근무하는 칸                                              |
| 추가 예정 / 삭제 예정 | —                   | 수정요청 카드를 눌렀을 때 그 요청이 승인되면 더해지거나 빠질 칸                                       |
| 신청 불가             | —                   | 근무를 신청할 수 없는 칸 (점심시간 11:30~13:00)                                                       |
| 정원 초과             | —                   | 칸 인원이 동시 근무 최대 인원을 넘은 칸                                                               |
